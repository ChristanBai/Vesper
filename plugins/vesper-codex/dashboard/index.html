        Setup guide

        Required read-only permissions

        In Trading 212, open Settings → API (Beta) → Permissions. Enable account, portfolio, Pies read and all History/Orders read permissions. Leave Orders - Execute and Pies - Write disabled.

        • History - OrdersRequired for buy and sell markers on the K-line.
        • Orders - ReadRead open orders and execution status.
        • History - Dividends / TransactionsRequired for cash-flow and trade review.
        • Pies - ReadRequired for reconciliation. Never enable Pies - Write.

        Research stack

        AI engines

        Technical analysis, portfolio review, backtesting and report generation run through MCP tools. This workspace is strictly read-only and cannot place or cancel orders.

        Available engines
        Technical analysisTrend, RSI, moving averages, volatility and drawdown.
        Trade reviewInvested capital, recovery, execution markers and benchmark.
        Risk reviewPosition weight, concentration, contribution and data-quality warnings.
        BacktestSMA crossover with equity curve and drawdown.
        Daily BriefUses real positions to calculate value, concentration, contribution, drag, recent orders and data-quality warnings.
        Technical analysisCalculates trend, RSI, moving averages, volatility, drawdown and a confidence score.
        News and fundamentalsYahoo, Finnhub and optional Longbridge data can add headlines, ratings and research evidence.
        BacktestTests research hypotheses with an explicit disclaimer; results are not execution instructions.
