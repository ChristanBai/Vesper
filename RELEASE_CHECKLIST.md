# VigilAlpha 0.1.0-dev.10 Release-readiness Checklist

Generated: 2026-10-09. This checklist applies only to this development release candidate.

## Automated gates

- [x] Syntax check and complete plugin test suite pass from source.
- [x] Installable ZIP and SHA-256 checksum are generated by `scripts/build-release.sh`.
- [x] The ZIP extracts into a clean temporary directory and passes syntax, tests and MCP startup.
- [x] Current tracked tree and Git history pass the documented secret/private-data scan.
- [x] Trading 212 client contains no write request path.
- [x] Existing state directories are repaired to `0700`; private files use `0600`.
- [ ] GitHub CI builds and uploads the same artifact shape.

## Product gates

- [x] Real read-only credential verification succeeds without exposing a secret.
- [x] `setup_status` reports Keychain and account-verification state correctly.
- [ ] Account total, currency, positions, Pies and history reconcile with Trading 212.
- [x] Same normalized input, cutoff and parameter version produce the same signal.
- [x] Missing, stale, limited or conflicting evidence degrades to a safe state.
- [ ] Inline setup card is completed manually in a newly opened Codex conversation.
- [ ] Inline charts and text fallback are checked in narrow and wide conversation layouts.

## Repository and publication gates

- [x] The intended public commit contains only the reviewed VigilAlpha product and compatibility
  files; no unrelated dirty work is included.
- [x] A fresh clone of that exact commit repeats the documented build and clean-package test.
- [x] Release notes accurately distinguish verified features from experimental research.
- [ ] GitHub Release is created from the reviewed commit, not from an uncommitted workstation.
- [ ] ZIP and `.sha256` are attached, downloadable and independently reverified.
- [ ] README download link resolves to the new non-draft release.
- [ ] Public Codex directory submission is handled separately after GitHub release verification.

Any unchecked account-truth, credential-safety, deterministic-signal or graphical-setup gate blocks
`v1.0`. A date or passing unit suite cannot waive those gates.
